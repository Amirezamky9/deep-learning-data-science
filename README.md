# Deep Learning & Data Science

مجموعه تمرین‌ها، پروژه‌ها و پیاده‌سازی‌های هفتگی دوره **دیپ‌لرنینگ و دیتا ساینس**.

## ساختار مخزن
تمرین‌ها به تفکیک هفته‌ها در پوشه `weeks/` قرار می‌گیرند. هر هفته شامل موارد زیر خواهد بود:
* **داکیومنت و خلاصه مفاهیم (`README.md`):** شرح مسئله، تئوری، فرمول‌ها و نتایج کلیدی.
* **نوتبوک‌های پیاده‌سازی (`notebooks/`):** کدهای تمیز با خروجی و توضیحات سلول به سلول.
* **اسکریپت‌های ماژولار (`src/`):** توابع کمکی و قابل استفاده مجدد در صورت نیاز.

> **نکته:** نقشه راه و سرفصل‌های تکمیلی پس از پیاده‌سازی گام‌به‌گام و بر اساس اسکریپت‌ها و مفاهیم آموخته‌شده به این بخش افزوده خواهد شد.
