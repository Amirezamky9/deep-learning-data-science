# Deep Learning & Data Science

مجموعه تمرین‌ها، پروژه‌ها و پیاده‌سازی‌های هفتگی دوره **دیپ‌لرنینگ و دیتا ساینس**.

## ساختار مخزن
* **`weeks/`:** تمرین‌ها و نوتبوک‌های هر هفته به همراه داکیومنت اختصاصی، فرمول‌ها و تحلیل خروجی‌ها.
* **`research/`:** پایگاه دانش و لاگ ریسرچ هفتگی شامل فایل اکسل (`research_log.xlsx`) و جدول مستندات منابع، مقالات ArXiv، چالش‌های کگل و راهکارهای حل مسئله.
* **`errors-and-lessons/`:** پایگاه ثبت تجربیات و عیب‌یابی؛ مستندسازی کامل تمام خطاها، علل ریشه‌ای (Root Cause) و درس‌های آموخته‌شده برای یادگیری عمیق‌تر («هر ارور، یک درس»).
* **`requirements.txt`:** پیش‌نیازها و کتابخانه‌های مورد نیاز پایتون.

> **نکته:** نقشه راه و سرفصل‌های تکمیلی پس از پیاده‌سازی گام‌به‌گام و بر اساس اسکریپت‌ها و مفاهیم آموخته‌شده به این بخش افزوده خواهد شد.
